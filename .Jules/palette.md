## 2024-05-18 - [Search Input UX]
**Learning:** Explicit clear buttons in search fields significantly improve navigation for both mouse and screen reader users on macOS.
**Action:** Always include a clear button with an appropriate accessibility label in custom search fields.
## 2023-10-27 - SwiftUI ContentUnavailableView Empty State
**Learning:** Using `ContentUnavailableView` provides a clean, native empty state pattern for lists and grids when collections (like filtered search results) are empty, saving custom layout effort and improving consistency.
**Action:** Always check if a view showing a list or grid handles the empty collection state gracefully, and implement `ContentUnavailableView` when appropriate.
